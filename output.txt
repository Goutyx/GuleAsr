GuleAsr – Perfume E-Commerce Website
Comprehensive Product, Design & Tech Stack Document
Prepared for Full Stack MERN Development

1. Product Overview
GuleAsr is a modern luxury perfume e-commerce platform offering 20 perfumes and 5 perfume oils.
It focuses on a futuristic UI, smooth user experience, and premium branding.
2. Design Philosophy
The design is inspired by futuristic UI concepts combined with luxury branding. It uses dark themes,
glassmorphism, animations, and sensory storytelling.
3. UI/UX Features
 Glassmorphism cards  Smooth animations  Luxury typography  Dark + gold theme  Interactive
product views  Responsive design
4. Key Pages
 Homepage with hero animation  Product listing page  Product detail page  Cart and checkout 
User dashboard
5. Tech Stack (MERN)
Frontend: React.js, Vite, Tailwind CSS, Framer Motion Backend: Node.js, Express.js Database:
MongoDB Authentication: JWT, bcrypt
6. Integrations & Tools
 Razorpay for payments  Cloudinary for images  Redux Toolkit for state management  React
Query for API handling
7. Architecture
Frontend communicates with backend APIs. Backend handles authentication, product
management, orders, and database operations using MongoDB.
8. Folder Structure
Frontend: /src/components /src/pages /src/services Backend: /controllers /models /routes
/middleware

9. Core Features
 User authentication  Product browsing  Cart system  Secure checkout  Admin panel  Order
tracking
10. Advanced Features
 AI-based recommendations  Wishlist  Reviews and ratings  Search autocomplete 
Personalized suggestions
11. Deployment
Frontend: Vercel Backend: Render Database: MongoDB Atlas
